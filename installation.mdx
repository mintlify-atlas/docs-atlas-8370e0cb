IQKeyboardManager can be installed using CocoaPods, Swift Package Manager (SPM), or Carthage. Choose the method that works best for your project.

## Installation Methods

<Tabs>
  <Tab title="Swift Package Manager">
    Swift Package Manager is the recommended method for installing IQKeyboardManager.

    ### Step 1: Add Package Dependency

    In Xcode, add the package:

    1. Go to **File → Swift Packages → Add Package Dependency...**
    2. Enter the repository URL:
       ```
       https://github.com/hackiftekhar/IQKeyboardManager.git
       ```
    3. Choose the version you want (latest is recommended)
    4. Click **Add Package**

    ### Step 2: Select Target

    Select your app target and click **Finish**.

    <Note>
    SPM automatically includes all subspecs and their dependencies.
    </Note>

    ### Package Dependencies

    IQKeyboardManager depends on several independent libraries:

    - `IQKeyboardNotification` (>= 1.0.6)
    - `IQTextInputViewNotification` (>= 1.0.9)
    - `IQKeyboardToolbarManager` (>= 1.1.4)
    - `IQKeyboardReturnManager` (>= 1.0.6)
    - `IQTextView` (>= 1.0.5)

    These are automatically managed by SPM.
  </Tab>

  <Tab title="CocoaPods">
    Install IQKeyboardManager using CocoaPods.

    ### Step 1: Add to Podfile

    Add the following line to your `Podfile`:

    ```ruby
    pod 'IQKeyboardManagerSwift'
    ```

    ### Step 2: Install

    Run the install command:

    ```bash
    pod install
    ```

    <Tip>
    By default, all subspecs are included. See below for including specific subspecs only.
    </Tip>

    ### Version-Specific Installation

    To install a specific version based on Swift compatibility:

    ```ruby
    # For Swift 5.7, 5.8, 5.9 (Xcode 15+)
    pod 'IQKeyboardManagerSwift', '8.0.0'

    # For Swift 5.5+ (Xcode 11+)
    pod 'IQKeyboardManagerSwift', '6.5.7'

    # For Swift 5.0+ (Xcode 10.2+)
    pod 'IQKeyboardManagerSwift', '6.2.1'
    ```

    Refer to the [Swift version compatibility table](#swift-version-compatibility) for more details.

    ### Installing Specific Subspecs

    To optimize your app size, include only the subspecs you need:

    <CodeGroup>
    ```ruby Core + Toolbar
    # Include core functionality and toolbar only
    pod 'IQKeyboardManagerSwift/Core'
    pod 'IQKeyboardManagerSwift/IQKeyboardToolbarManager'
    ```

    ```ruby Core + Resign
    # Include core functionality and tap-to-resign only
    pod 'IQKeyboardManagerSwift/Core'
    pod 'IQKeyboardManagerSwift/Resign'
    ```

    ```ruby All Features
    # Include all features (default)
    pod 'IQKeyboardManagerSwift'
    ```
    </CodeGroup>

    ### Available Subspecs

    | Subspec | Description | Dependencies |
    |---------|-------------|-------------|
    | `Core` | Basic keyboard distance management (always required) | IQKeyboardNotification, IQTextInputViewNotification |
    | `Appearance` | Keyboard appearance configuration | IQTextInputViewNotification |
    | `IQKeyboardReturnManager` | Return key handling | IQKeyboardReturnManager |
    | `IQKeyboardToolbarManager` | Toolbar with Previous/Next/Done buttons | IQKeyboardToolbarManager |
    | `IQTextView` | UITextView with placeholder support | IQTextView |
    | `Resign` | Tap-to-resign keyboard functionality | IQTextInputViewNotification |
  </Tab>

  <Tab title="Carthage">
    Install IQKeyboardManager using Carthage.

    ### Step 1: Add to Cartfile

    Add the following line to your `Cartfile`:

    ```ogdl
    github "hackiftekhar/IQKeyboardManager"
    ```

    ### Step 2: Build Frameworks

    Run Carthage to build the frameworks:

    ```bash
    carthage update --use-xcframeworks
    ```

    ### Step 3: Add Framework to Project

    1. In Xcode, go to your target's **General** settings
    2. Drag `IQKeyboardManagerSwift.xcframework` from the Carthage/Build folder into the **Frameworks, Libraries, and Embedded Content** section
    3. Ensure it's set to **Embed & Sign**

    <Warning>
    Only add `IQKeyboardManagerSwift.xcframework`. Do not add both Objective-C and Swift versions.
    </Warning>
  </Tab>
</Tabs>

## Source Code Installation

<Warning>
Source code installation is **not supported** since version 7.2.0.
</Warning>

The library now depends on several independent libraries, which makes source code installation complex and prone to compilation issues. Please use one of the package managers above.

## Verification

After installation, verify that IQKeyboardManager is properly integrated:

### Step 1: Import the Framework

In your `AppDelegate.swift`, add the import statement:

```swift
import IQKeyboardManagerSwift
```

### Step 2: Check for Errors

Build your project (⌘+B) and ensure there are no import errors.

<Tip>
If you see a "No such module" error, clean the build folder (⌘+Shift+K) and rebuild.
</Tip>

### Step 3: Test Basic Functionality

Add this code to verify the singleton is accessible:

```swift
func application(_ application: UIApplication, 
                 didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
    
    print("IQKeyboardManager available: \(IQKeyboardManager.shared)")
    return true
}
```

If this prints successfully, the installation is complete!

## Troubleshooting

<AccordionGroup>
  <Accordion title="Module 'IQKeyboardManagerSwift' not found">
    This usually means the framework wasn't properly linked. Try:

    1. Clean build folder: **Product → Clean Build Folder** (⌘+Shift+K)
    2. Delete derived data: `~/Library/Developer/Xcode/DerivedData`
    3. Close and reopen Xcode
    4. Rebuild the project

    **For CocoaPods:**
    ```bash
    pod deintegrate
    pod install
    ```

    **For SPM:**
    - File → Swift Packages → Reset Package Caches
    - File → Swift Packages → Resolve Package Versions
  </Accordion>

  <Accordion title="Build errors after installation">
    If you see build errors after installing:

    1. Ensure your deployment target is iOS 13.0 or later
    2. Check that you're using a compatible Xcode version (13+)
    3. Verify your Swift version matches the compatibility table
    4. Make sure you're not mixing Swift and Objective-C versions
  </Accordion>

  <Accordion title="Carthage build fails">
    If Carthage fails to build:

    ```bash
    # Try using xcframeworks
    carthage update --use-xcframeworks --platform iOS

    # Or specify the new build system
    carthage update --use-xcframeworks --platform iOS --no-use-binaries
    ```
  </Accordion>

  <Accordion title="CocoaPods integration issues">
    If CocoaPods shows warnings or errors:

    ```bash
    # Update CocoaPods
    sudo gem install cocoapods

    # Update repository
    pod repo update

    # Clear cache and reinstall
    pod cache clean --all
    pod deintegrate
    pod install
    ```
  </Accordion>

  <Accordion title="Xcode 15+ Code Signing Issues">
    If you encounter code signing issues in Xcode 15+:

    The library includes `ENABLE_USER_SCRIPT_SANDBOXING = NO` in its xcconfig to prevent build issues. If you still have problems, add this to your project's build settings or Podfile:

    ```ruby
    post_install do |installer|
      installer.pods_project.targets.each do |target|
        target.build_configurations.each do |config|
          config.build_settings['ENABLE_USER_SCRIPT_SANDBOXING'] = 'NO'
        end
      end
    end
    ```
  </Accordion>
</AccordionGroup>
