## Overview

Version 7.0 introduces a cleaner, more organized API structure with configuration objects and the `.iq` wrapper pattern for UIView extensions. This improves code clarity and reduces namespace pollution.

<Info>
  **Key Change**: Most UIView extension properties now use the `.iq` namespace wrapper pattern.
</Info>

## Breaking Changes

### Removed Features

The following properties and methods have been removed:

```swift
// Removed in v7
IQKeyboardManager.shared.preventShowingBottomBlankSpace // [!code --]
IQKeyboardManager.shared.shouldFixInteractivePopGestureRecognizer // [!code --]
IQKeyboardManager.shared.canAdjustAdditionalSafeAreaInsets // [!code --]

// Removed registration methods
IQKeyboardManager.shared.registerTextFieldViewClass(_:didBeginEditingNotificationName:didEndEditingNotificationName:) // [!code --]
IQKeyboardManager.shared.unregisterTextFieldViewClass(_:didBeginEditingNotificationName:didEndEditingNotificationName:) // [!code --]
```

### Removed UIViewController Property

```swift
// Removed IBOutlet
@IBOutlet var IQLayoutGuideConstraint: NSLayoutConstraint? // [!code --]
```

## IQKeyboardManager Configuration Changes

Many properties have been renamed for consistency:

<CodeGroup>
```swift v6 Properties

IQKeyboardManager.shared.toolbarManageBehaviour
IQKeyboardManager.shared.shouldToolbarUsesTextFieldTintColor
IQKeyboardManager.shared.overrideKeyboardAppearance

```

```swift v7 Properties
IQKeyboardManager.shared.resignOnTouchOutside // [!code ++]

// Moved to configuration object ↓

toolbarConfiguration.useTextFieldTintColor // [!code ++]
// Moved to keyboard configuration ↓
keyboardConfiguration.overrideAppearance // [!code ++]

```
</CodeGroup>

## Keyboard Listener Changes

Keyboard state monitoring has been moved to a dedicated `IQKeyboardListener` class:

<CodeGroup>
```swift v6 Keyboard Monitoring
IQKeyboardManager.shared.registerKeyboardSizeChange(identifier: "myId") { size in
    print("Keyboard size: \(size)")
}
IQKeyboardManager.shared.unregisterKeyboardSizeChange(identifier: "myId")

let isShowing = IQKeyboardManager.shared.keyboardShowing
let frame = IQKeyboardManager.shared.keyboardFrame
```

```swift v7 Keyboard Listener
let listener = IQKeyboardListener()

listener.registerSizeChange(identifier: "myId") { size in
    print("Keyboard size: \(size)")
}
listener.unregisterSizeChange(identifier: "myId")

let isShowing = listener.keyboardShowing
let frame = listener.frame
```
</CodeGroup>

## Migration Steps

<Steps>
  <Step title="Update Dependency">
    Update your `Podfile` or `Package.swift` to version 7.0+
    
    ```ruby
    # CocoaPods
    pod 'IQKeyboardManagerSwift', '~> 7.0'
    ```
    
    ```swift
    // Swift Package Manager
    .package(url: "https://github.com/hackiftekhar/IQKeyboardManager.git", from: "7.0.0")
    ```
  </Step>
  
  <Step title="Install Dependencies">
    ```bash
    # CocoaPods
    pod install
    
    # Swift Package Manager
    # File > Packages > Update to Latest Package Versions
    ```
  </Step>
  
  <Step title="Update Property Names">
    Use find-and-replace to update renamed properties:
    
    - `shouldResignOnTouchOutside` → `resignOnTouchOutside`
    - `shouldPlayInputClicks` → `playInputClicks`
    - `overrideKeyboardAppearance` → `keyboardConfiguration.overrideAppearance`
    - `keyboardAppearance` → `keyboardConfiguration.appearance`
  </Step>
  
  <Step title="Migrate Toolbar Configuration">
    Move toolbar settings to configuration objects:
    
    ```swift
    // Before
    IQKeyboardManager.shared.toolbarTintColor = .blue
    IQKeyboardManager.shared.shouldShowToolbarPlaceholder = true
    
    // After
    IQKeyboardManager.shared.toolbarConfiguration.tintColor = .blue
    IQKeyboardManager.shared.toolbarConfiguration.placeholderConfiguration.showPlaceholder = true
    ```
  </Step>
  
  <Step title="Update UIView Extensions">
    Add `.iq` wrapper to all UIView extension properties:
    
    ```swift
    // Before
    textField.keyboardDistanceFromTextField = 10
    scrollView.shouldIgnoreScrollingAdjustment = true
    
    // After
    textField.iq.distanceFromKeyboard = 10
    scrollView.iq.ignoreScrollingAdjustment = true
    ```
  </Step>
  
  <Step title="Update Keyboard Monitoring">
    If you use keyboard size monitoring, migrate to `IQKeyboardListener`:
    
    ```swift
    // Before
    IQKeyboardManager.shared.registerKeyboardSizeChange(identifier: "id") { size in }
    
    // After
    let listener = IQKeyboardListener()
    listener.registerSizeChange(identifier: "id") { size in }
    ```
  </Step>
  
  <Step title="Build and Test">
    - Build your project and fix compilation errors
    - Test all keyboard interactions
    - Verify toolbar customizations still work
  </Step>
</Steps>

## Complete Example

Here's a before/after comparison of typical AppDelegate configuration:

<CodeGroup>
```swift v6 Configuration
import IQKeyboardManagerSwift

func application(_ application: UIApplication, didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
    IQKeyboardManager.shared.enable = true
    
    // Touch outside to dismiss
    IQKeyboardManager.shared.shouldResignOnTouchOutside = true
    
    // Toolbar configuration
    IQKeyboardManager.shared.enableAutoToolbar = true
    IQKeyboardManager.shared.toolbarTintColor = .systemBlue
    IQKeyboardManager.shared.shouldShowToolbarPlaceholder = true
    IQKeyboardManager.shared.placeholderFont = .systemFont(ofSize: 14)
    IQKeyboardManager.shared.toolbarDoneBarButtonItemText = "Done"
    
    // Keyboard appearance
    IQKeyboardManager.shared.overrideKeyboardAppearance = true
    IQKeyboardManager.shared.keyboardAppearance = .dark
    
    return true
}
```

```swift v7 Configuration
import IQKeyboardManagerSwift

func application(_ application: UIApplication, didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
    let manager = IQKeyboardManager.shared
    manager.enable = true
    
    // Touch outside to dismiss
    manager.resignOnTouchOutside = true
    
    // Toolbar configuration
    manager.enableAutoToolbar = true
    manager.toolbarConfiguration.tintColor = .systemBlue
    manager.toolbarConfiguration.placeholderConfiguration.showPlaceholder = true
    manager.toolbarConfiguration.placeholderConfiguration.font = .systemFont(ofSize: 14)
    manager.toolbarConfiguration.doneBarButtonConfiguration?.title = "Done"
    
    // Keyboard appearance
    manager.keyboardConfiguration.overrideAppearance = true
    manager.keyboardConfiguration.appearance = .dark
    
    return true
}
```
</CodeGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Property not found on UITextField">
    **Cause**: Forgot to add `.iq` wrapper
    
    **Solution**:
    ```swift
    // Wrong
    textField.distanceFromKeyboard = 10
    
    // Correct
    textField.iq.distanceFromKeyboard = 10
    ```
  </Accordion>
  
  <Accordion title="Cannot find 'toolbarTintColor' in scope">
    **Cause**: Property moved to configuration object
    
    **Solution**:
    ```swift
    // Wrong
    IQKeyboardManager.shared.toolbarTintColor = .blue
    
    // Correct
    IQKeyboardManager.shared.toolbarConfiguration.tintColor = .blue
    ```
  </Accordion>
  
  <Accordion title="Keyboard monitoring not working">
    **Cause**: Need to use `IQKeyboardListener` instead
    
    **Solution**:
    ```swift
    let listener = IQKeyboardListener()
    listener.registerSizeChange(identifier: "myId") { size in
        // Handle keyboard size change
    }
    ```
  </Accordion>
</AccordionGroup>
